# Large-Scale-Data-Engineering

Coursework files of LSDE
Cloud computing and system set-up using AWS (Cloud Foundations)

Part 1: A written task to design the architecture of a simple application on AWS cloud, where
you are required to have a deep understanding of AWS services and how they work together within
an application. The design should demonstrate your knowledge of AWS services covered throughout
the entire LSDE course.

Part 2: A combined practical and written activity architecting a scaling application on the Cloud, where
you will be required to use the knowledge gained and a little further research to implement the scaling
infrastructure, followed by a report that will focus on your experience in the practical activity together
with knowledge gained in the entire LSDE course.
